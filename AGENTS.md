# Project Instruction

## Project Goal

- This project is a meta repo to store RPM Specfiles for Pulpcore Packaging
- Always respect the fedora packaging guideline
- This repo target python packages and it's dependency

## Project tools

- Always use rpm guidelines for packages, specfiles should be stored inside of packages/python-<package-name>
- Obal, https://github.com/theforeman/obal, can be used to bump packages and automate tasks

## Python Version

- The packages are packaged for Python 3.12
